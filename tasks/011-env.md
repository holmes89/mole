# 011: Environments

## Task

Create the `env` package: a chained environment.

## Context

- Change: create `env/env.go`, `env/env_test.go`
- The package imports nothing from this module. It stores `any`, so both values and types can use it.

```go
package env

type Env struct {
	vars   map[string]any
	parent *Env
}

func New(parent *Env) *Env
func (e *Env) Define(name string, v any)       // sets name in this frame
func (e *Env) Get(name string) (any, bool)     // looks in this frame, then the parents
```

## Done when

`go test ./env/ -timeout 30s` passes: a child sees the parent's names; a child's `Define` shadows without changing the parent; `Get` of a missing name returns false.
