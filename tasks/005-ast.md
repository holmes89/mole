# 005: AST nodes and `ast.Show`

Depends on: 002.

## Task

Create the `ast` package: node types and a printer used by parser tests.

## Context

- Change: create `ast/ast.go`, `ast/show.go`, `ast/show_test.go`
- `ast/ast.go`, exactly:

```go
package ast

import "github.com/holmes89/mole/token"

type Expr interface{ Pos() token.Pos }
type Pat interface{ Pos() token.Pos }
type Dec interface{ Pos() token.Pos }

type Node struct{ P token.Pos }

func (n Node) Pos() token.Pos { return n.P }

// Expressions
type IntLit struct { Node; Value int64 }
type StrLit struct { Node; Value string }
type Var struct { Node; Name string }      // x, +, Int.toString
type Con struct { Node; Name string }      // Leaf, true, nil
type Tuple struct { Node; Elems []Expr }   // zero elements is unit
type List struct { Node; Elems []Expr }
type App struct { Node; Fn, Arg Expr }
type If struct { Node; Cond, Then, Else Expr }
type Fn struct { Node; Arms []Arm }
type Let struct { Node; Decs []Dec; Body []Expr }
type Seq struct { Node; Exprs []Expr }
type AndAlso struct { Node; L, R Expr }
type OrElse struct { Node; L, R Expr }

type Arm struct { Pat Pat; Body Expr }

// Patterns
type PWild struct{ Node }
type PVar struct { Node; Name string }
type PTuple struct { Node; Elems []Pat }   // zero elements is unit

// Declarations
type ValDec struct { Node; Pat Pat; Expr Expr }
type FunDec struct { Node; Name string; Clauses []Clause }
type Clause struct { Pats []Pat; Body Expr }
```

(gofmt will put each field on its own line. That is fine.)

- Nodes are always used as pointers (`&ast.IntLit{Value: 5}`), so `Show` switches on `*ast.IntLit` and so on.

- `ast/show.go`: `func Show(n any) string` returns a compact s-expression. It accepts any Expr, Pat, or Dec:

| Node | Output |
|---|---|
| IntLit 5, IntLit -5 | `5`, `-5` |
| StrLit | Go `%q` form: `"hi"` |
| Var, Con, PVar | the name |
| Tuple, PTuple | `(tuple a b)`; with zero elements `()` |
| List | `(list a b)`; empty is `(list)` |
| App | `(app f x)` |
| If | `(if c t e)` |
| Fn | `(fn (p body) (p body))` |
| Let | `(let (dec dec) body body)` |
| Seq | `(seq a b)` |
| AndAlso, OrElse | `(andalso a b)`, `(orelse a b)` |
| PWild | `_` |
| ValDec | `(val p e)` |
| FunDec | `(fun name ((p p) body) ((p p) body))` |

- An unknown node prints as `<?>`.

## Done when

`go test ./ast/ -timeout 30s` passes, with cases built by hand:

- `App{Fn: Var{Name:"+"}, Arg: Tuple{Elems: [IntLit 1, IntLit 2]}}` shows `(app + (tuple 1 2))`
- `Tuple{}` shows `()`
- `Fn{Arms: [{PVar x, Var x}]}` shows `(fn (x x))`
- `ValDec{Pat: PTuple[PVar a, PWild], Expr: IntLit 1}` shows `(val (tuple a _) 1)`
